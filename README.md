# MyFinances

App Android personale per pianificazione finanziaria Casa + Personale, sviluppata in Kotlin e Jetpack Compose.

## Documentazione

La documentazione aggiornata del progetto e disponibile in [`docs/`](./docs/README.md).

## Stato

La shell Compose, la navigazione principale e il bootstrap Hilt sono funzionanti. Lo sviluppo procede per milestone, iniziando dalla Fase 1 locale con Room e dalla sezione Casa.
