# MyFinances - Documentazione

Questa cartella contiene la documentazione viva del progetto. Le specifiche vengono aggiornate insieme al codice quando una decisione funzionale o architetturale cambia.

## Documenti correnti

- [Specifiche generali - v3](./MyFinances_Specifiche_Progetto_v3.pdf) - Obiettivi dell'app, sezioni, regole di dominio, architettura Android e roadmap Step 1/2/3.
- [Schema Room Casa - definitivo per la prima milestone](./MyFinances_Schema_Room_Casa_Definitivo.pdf) - Tabelle, campi, tipi, vincoli, relazioni ed esempi della prima implementazione della sezione Casa.

## Regola di manutenzione

Quando cambiamo una decisione importante:

1. aggiorniamo prima la specifica interessata;
2. verifichiamo che lo schema dati resti coerente;
3. implementiamo il codice;
4. aggiorniamo questo indice se viene aggiunto un nuovo documento.

La documentazione deve descrivere lo stato deciso del progetto, non soltanto il codice gia implementato.
